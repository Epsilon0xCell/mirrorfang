# Security Policy

## Reporting

Report vulnerabilities in this project privately to the author, Gavin Blacklock
(Epsilon0xCell), through GitHub private vulnerability reporting on the
repository once it is published, or through the contact listed on the
Epsilon0xCell GitHub profile. Do not open a public issue for a vulnerability.

## Scope

All log samples in this pack are synthetic. No real credentials, hosts, or production logs are included. Rules are provided for defensive detection use.

## Supported versions

Only the latest release on the default branch is supported.
